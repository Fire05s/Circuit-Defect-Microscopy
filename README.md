# Defect Microscopy for Integrated Circuit Design

Our goal is to take the [Openflexure 3D-printable microscope](https://build.openflexure.org/openflexure-microscope/v6.1.5/docs/#/index) and modify it to support capturing clear images of chip surfaces. This includes building upon previous papers/projects that enhanced the microscope’s resolution (“super-resolution”). The modified system should be able to identify and flag surface level defects such as cracks and potential shorts between circuit elements (from residue). The resulting device can help fulfill one stage of chip-validation, especially accessible for students and hobbyists.

# Repo Organization

**Datasets**: We will store the various datasets we are using for large-scale training/testing here.

**Notebooks**: Initial prototyping of our models will be done on Google Collab.

**Setup**: This contains basic info/scripts on libraries that are being used.

**Src**: This is where the model is trained and can be deployed from.
